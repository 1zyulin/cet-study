# CET Study · 四六级学习室

在自己的电脑上运行，用 Edge 或 Chrome 学习四级、六级。题库、词书和学习记录保存在本地；配置自己的大模型 API 后，可以围绕题目提问，并获得写作、翻译的参考评分。

本项目基于 [CET6-Full-Process-Learning](https://github.com/HCLEMINI/CET6-Full-Process-Learning) 的部分服务端逻辑改造，采用 MIT 许可，保留原作者署名。复用范围见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## v0.1 的学习流程

- 导入四级、六级 JSON 内容包，按套卷练习阅读、听力、写作和翻译。
- 选择题依照题库答案判分，并查看解析与错题记录。
- 配置兼容 Chat Completions 的模型 API，结合当前题目答疑，批改写作与翻译。
- 导入个人词书，练习单词并记录复习进度。
- 上传本地听力音频，通过题库中的音频地址练习；逐句精听需要提供对应时间轴。
- 将本地学习数据导出为备份，或从备份恢复。

**新安装默认是空题库、空词书，不再自动添加演示练习或演示单词。** `examples/` 中的原创样例仅供查看导入格式，需要时可以自己导入。公开仓库不附带第三方真题、考试音频或红宝书等商业词书；可以使用下文的工具取得资料并导入自己的电脑。完整真题建设进度见 [路线图](docs/ROADMAP.md)。

题库第一阶段整理范围为 **2023—2025 年**。本地已从社区来源转换并导入四级 **21 组**、六级 **18 组**写作与翻译，共 **39 组、78 题**。这些内容保持 `source.verified: false`，参考译文是社区整理内容，尚未核验为官方答案。公开仓库不附带第三方原题或音频；新用户可以使用转换工具在自己的电脑取得并导入。见[近三年资料来源与整理进度](docs/近三年题库整理.md)。

本地已导入 **900 道阅读题**：四级 2024、2025 年 6 月和 12 月各 3 套，共 12 套、360 题；六级 2023、2024、2025 年 6 月和 12 月各 3 套，共 **18 套、540 题**。每套包含选词填空 26—35、长篇匹配 36—45、仔细阅读 46—55，共 30 题。阅读保留 `verified: false`，按对应来源答案判分，不代表官方核验。网页“真题练习”可搜索“阅读”或年份。

当前本地合计 **69 个练习包、978 道题**，包括上述阅读以及写作、翻译。四级 2023 年阅读和完整听力仍有缺口。原听力来源的 18 条记录中只有 3 条结构齐全，其余存在空题或缺失选项，音频尚未加入，不能称为完整三年全科题库。网页中的 **121 个来源文件索引记录**仅是元数据，不等于 121 套试卷。

本地词书已取得 [ECDICT](https://github.com/skywind3000/ECDICT) 的真实词汇数据：**四级 3,849 词、六级 5,805 词**。六级词表包含四级基础，共计 5,805 个不同单词；同一个词在多本词书中共享复习记录。全部含中文释义，四级 12 词、六级 31 词缺音标，未添加上游没有提供的例句。它们是 ECDICT 标签词表，不是红宝书或其他出版社词书。

## 在 Windows 上启动

需要 Python 3.10 或更新版本，以及 Edge / Chrome。详细的下载安装、首次使用和常见问题步骤见 [Windows 上手指南](docs/Windows上手指南.md)。下载并完整解压仓库后，**双击 `start.cmd`** 即可启动。学习期间保持启动窗口打开；关闭窗口后，本地网页会显示“连接被拒绝”。启动失败时，窗口会保留错误提示。

也可以在项目文件夹打开终端，运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

脚本首次创建项目 `.venv` 并安装依赖，之后启动应用；不会安装项目之外的 Python 包。`start.cmd` 与上面的命令都只为本次进程设置执行策略，不修改系统策略。

浏览器自动打开；也可手动访问 [http://127.0.0.1:8765](http://127.0.0.1:8765)。服务运行期间保持启动终端打开；按 `Ctrl+C` 停止。

如果希望手动操作，无需激活环境，直接运行：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

没有 `py` 命令但 `python --version` 正常时，将第一行的 `py -3` 换为 `python`。

在 macOS / Linux 上，也可以使用 Python 环境运行相同的应用：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py
```

默认服务只监听 `127.0.0.1`，供本机使用。v0.1 按单人本地应用设计，没有多人账户或公网部署流程。

### Docker 备用部署方式

仓库提供 Docker 配置，可以在项目根目录执行：

```sh
docker build -t cet-study .
docker run --rm -p 127.0.0.1:8765:8765 -v cet-study-data:/app/data cet-study
```

随后访问同一个本地网页地址。学习数据保存在 `cet-study-data` 卷中；删除容器不会自动删除该卷。**Docker 部署尚未实测**，当前优先使用上面的 Python 启动方式。

## 第一次使用

1. 新安装先按下文取得题库与词书，或导入自己的文件。已有本地数据会保留；在“真题练习”选择级别、搜索“阅读”，提交选择题查看判分。
2. **可选：**需要 AI 答疑或批改时，再在“模型设置”填写 API 服务地址、模型名和自己的密钥，点击“保存设置”。也可以先学习，之后再接入 API。
3. 在“题库与数据”选择“导入题库”或“上传音频”；在“单词复习”选择“导入词书”。示例与字段说明见 [内容格式](docs/content-format.md)。
4. 在“题库与数据”使用“导出备份”保存题库、单词和作答记录。更换电脑时安装应用并选择“恢复备份”；音频与模型设置需另外处理，详见下文。

没有云端 API 密钥时，题库导入、客观题判分、单词练习和本地音频播放仍可使用。云端 AI 调用需要网络与服务商额度；本机模型按其实际配置运行。调用时，相关题目、作答或聊天内容会发送到所配置的模型接口。

## 配置 AI

填写能够接受 `POST /chat/completions` 的兼容接口。**Base URL 填接口根地址，不包含 `/chat/completions`**；例如接口要求版本前缀时填写 `https://api.example.com/v1`。服务端会追加 `/chat/completions`。

模型名使用服务商提供的准确标识，例如 DeepSeek 服务中的 `deepseek-chat`。使用其他兼容服务时替换 Base URL、模型名和密钥即可；不同服务的兼容性仍需实际验证。

外部服务地址须使用 HTTPS 并提供 API Key；本机模型可以使用 `http://localhost:端口/v1` 或 `http://127.0.0.1:端口/v1`，支持不填写密钥的接口。这里的端口和模型名应按本机模型服务的实际配置填写。

API 密钥由本地服务保存在本地设置中，不写入网页源码，也不随代码仓库提交。保存设置并不表示已经成功调用模型。AI 评分标注为 **15 分制参考评分**，不是官方评分，更不是四六级 710 分制成绩。AI 输出可能有误，应结合题库原始答案和人工判断。

## 题库与词书

已提供本地社区资料转换工具。在 `cet-study` 项目目录打开终端，完成依赖安装后执行：

```powershell
.\.venv\Scripts\python.exe tools\import_sources.py --download --import-local
```

该命令需要联网，从支持的社区来源下载文本，只转换写作、翻译并导入本地数据库。转换器读取来源 JavaScript 的数据字面量，不执行来源代码。原始资料与转换结果分别保存在 `data/source-materials/` 和 `data/imports/`，这些路径均不进入公开仓库。完成后刷新网页查看练习。

本轮已验证已有本地资料的转换与导入，**此命令的联网下载流程尚未实测**；来源更新或网络问题可能导致转换失败，导入数量以本机生成的 `data/imports/import-report.json` 为准。详细来源、内容缺口与步骤见 [近三年题库整理](docs/近三年题库整理.md)。

阅读另有批量转换工具 `tools/import_recent_reading.py`，目前支持四级 2024—2025 年 12 套阅读。它需要额外的 PDF 提取依赖，安装与导入步骤见 [阅读导入说明](docs/近三年题库整理.md#在自己的电脑取得四级阅读)。

六级使用 `tools/import_cet6_reading.py`，PDF / Word 转换的可选依赖为 `pdfplumber`、`pypdf`、`python-docx`。它默认读取公开的答案字母、出处与少量标签校正索引；完整题目仍从对应来源下载到本地，转换结果不随仓库发布。原卷获取、索引与个人校对文件的使用步骤见 [六级阅读说明](docs/近三年题库整理.md#六级阅读原卷与备用文本)。

### 取得四六级词书

在已完成首次启动的项目目录打开终端，执行：

```powershell
.\.venv\Scripts\python.exe tools\import_wordbooks.py --download
```

工具联网下载约 66MB 的 ECDICT CSV，核对固定版本、文件大小和 Git blob SHA 后，生成 `data/imports/cet4-words.json`、`cet6-words.json`、来源统计 `wordbook-import-report.json` 和 `ECDICT-LICENSE.txt`。**联网下载、转换与全部词条校验已实测成功。** 没有联网需要时，可在源 CSV 已缓存的情况下去掉 `--download` 再转换；来源不匹配时会停止并提示错误。

它只生成导入文件，不自动修改数据库。在网页“单词复习”点击“导入词书”，先选择 `cet4-words.json`，再将“词书名称”改为 **`ECDICT 四级词表（CET4）`** 并导入；六级文件同样操作，名称填 **`ECDICT 六级词表（CET6）`**。选择文件后会自动填入文件名，因此要在选择文件之后修改名称。通过上方四级 / 六级和“选择词书”切换学习范围。

词表按上游 `cet4` / `cet6` 标签筛选，不声明是最新官方大纲的完整清单。转换工具会记录缺失字段和跳过原因，不自行造词或补写释义。ECDICT 采用 MIT，保留 `Copyright (c) 2025 Linwei` 与许可全文；下载数据和转换结果留在本地 `data/`，不随本仓库发布。

- [原创格式样例](examples/demo-exams.json)：可作为阅读、写作、翻译数据格式的完整例子，不会自动入库。
- [原创词书格式样例](examples/demo-words.csv)：CSV 列名为 `word,meaning,phonetic,example`，不会自动入库。
- [空白真题模板](examples/empty-real-exam-template.json)：未填写完整，缺少选择题答案；**不能直接导入**。补齐原文、答案、来源与校对状态后再使用。

用户导入内容默认留在 `data/`。标记为真题并不代表平台已替用户核验真实性；`source.verified` 记录提供者的校对声明。发布内容包前，应核实原题、音频、解析和词书的使用权。软件 MIT 许可不自动覆盖第三方内容。

## 数据与备份

本地 `data/` 保存学习数据库、导入内容、音频和设置；该目录已被 `.gitignore` 排除。卸载、迁移或清理项目目录前，请先备份。

网页导出的 JSON 备份包含 `exams`（题库）、`attempts`（作答记录）和 `words`（单词、所属词书与复习数据），**不包含模型设置、API Key 或音频文件**。多词书使用 `books` 列表保存，同词复习进度只保留一份；旧版本仅有 `book` 的备份也能恢复。迁移电脑时，除 JSON 备份外，还需单独备份并复制 `data/audio/`，保留音频文件名，然后重新填写模型设置。

恢复操作会替换当前题库、作答记录与单词。恢复前，服务自动在 `data/recovery/` 保存当前学习数据快照；如需撤销，可将对应快照作为备份再次导入。快照同样不包含模型密钥和音频。备份与快照应作为个人资料妥善保存。

本地数据并非云端同步，API 密钥也不由 GitHub 托管。不要把自己的 `data/`、`.env`、音频或备份文件加入公开仓库。
