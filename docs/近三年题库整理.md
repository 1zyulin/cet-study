公开仓库只发布程序、转换工具、来源索引和原创格式参考，不附带上述第三方原题与音频。新安装默认空库，不自动添加样例。当前本地已移除演示练习和对应演示记录；练习标题不再带“待校对”，来源中的 `verified: false` 仍保留，不据此声称已核验为官方题库。本地整理不需要等公开内容包授权后才开始；向公开仓库提交或重新分发第三方正文时，仍应核实适用的权利范围。

## 在自己的电脑取得写作与翻译

先按照 [Windows 上手指南](Windows上手指南.md) 安装依赖。在 **`cet-study` 项目目录**打开 PowerShell，执行：

```powershell
.\.venv\Scripts\python.exe tools\import_sources.py --download --import-local
```

工具执行以下操作：

1. 联网获取支持的社区写作与翻译文本，保存在 `data/source-materials/`。
2. 解析 Markdown 或 JavaScript 中的题目数据，转换为统一内容包。JavaScript 仅解析数据字面量，**不会执行来源代码**。
3. 对生成内容包做字段校验，并保留来源、文件 SHA-256 与未校对状态。
4. 写入 `data/imports/community-subjective-2023-2025.json` 和 `data/imports/import-report.json`。
5. 在导入前保存 `data/imports/before-source-import-backup.json`，然后将题目合并到本地学习数据库。

完成后刷新学习网页，在“真题练习”查看导入内容。转换错误或网络失败时，先阅读终端提示；不要把失败记录当成已导入内容。

本轮已对已有本地来源文件完成转换与导入测试。**上述命令的联网下载流程尚未实测**；它需要可访问来源网站的网络。社区资料今后可能变化，实际组数、题目数和来源指纹以本机的 `import-report.json` 为准。

若已经取得工具所需的同名来源文件并放入 `data/source-materials/`，可以跳过下载，执行：

```powershell
.\.venv\Scripts\python.exe tools\import_sources.py --import-local
```

所有来源文本、转换结果和本地数据库都在已被 `.gitignore` 排除的 `data/` 内。不要把个人备份或第三方资料加入公开代码提交。

## 在自己的电脑取得四级阅读

在 `cet-study` 项目目录中，先为项目独立环境安装 PDF 提取所需的可选依赖。若环境没有 pip，第一行会补齐它；这些操作只作用于 `.venv`：

```powershell
.\.venv\Scripts\python.exe -m ensurepip --upgrade
.\.venv\Scripts\python.exe -m pip install pdfplumber pypdf
.\.venv\Scripts\python.exe tools\import_recent_reading.py --download --import-local
```

该批量工具从 [CET46-Resources](https://github.com/0609x/CET46-Resources) 获取上表列出的 12 份四级原卷 PDF。下载时核对索引中的 **Git blob SHA、文件大小和 PDF 文件头**；来源文件变化或下载不完整时会提示失败，需要检查索引后再处理，不跳过核对强行入库。

转换器优先使用 `pdfplumber` 按页面位置提取文本，减少单词内部异常空格；没有该库时尝试 `pypdf`。题目、选项与原卷末页答案键经过结构检查后转换，缺失或不能识别的结构会报错。自动检查不能替代人工全文校对，所以入库后仍为未校对状态。

若所需同名 PDF 已在 `data/source-materials/`，可跳过网络下载：

```powershell
.\.venv\Scripts\python.exe tools\import_recent_reading.py --import-local
```

本轮已用已有本地 PDF 缓存实测批量转换、导入 **12 套、360 题，失败数为 0**。带 `--download` 的联网下载流程尚未实测；下载与安装可选依赖均需要网络。

批量结果保存在 `data/imports/reading-recent-cet4.json`，统计与失败项保存在 `data/imports/reading-recent-report.json`。工具可能保存部分成功结果，因此应查看报告里的 `papers`、`questions` 和 `failures`，不要仅根据命令结束就认定 12 套全部完成。每次入库前会在 `data/recovery/` 备份现有学习数据。

完成后 **刷新网页**，在“真题练习”搜索 **“阅读”**，或选择四级并按考次查看新内容。批量命令只处理 12 份四级原卷，不会自动取得六级的局部阅读包或听力。

另有 `tools/import_reading.py` 单文件工具，可通过 `--pdf`、`--level`、`--year`、`--session`、`--set` 和 `--source-url` 指定原卷，并用 `--answers` 提供独立答案 PDF 交叉核对。不提供 `--answers` 时读取原卷末页答案键。这个单文件工具的六级重排版只支持仔细阅读，须显式使用 `--careful-only`，不会将其标成完整阅读。六级三部分阅读使用下一节的专用转换器。查看详细参数：

```powershell
.\.venv\Scripts\python.exe tools\import_reading.py --help
```

## 六级阅读：原卷与备用文本

六级专用工具按 2023—2025 年的 6 月、12 月和各考次三套材料整理。优先取得原卷及对应答案；PDF 排版不能完整提取时，结合备用仓库文本进行转换，并保留所用来源和指纹。备用文本不自动等于已校对原卷，答案必须对应同一考次、套卷和题号。

六级转换还会读取 Word 原卷，需安装 `python-docx`。在项目独立环境安装这些可选依赖后，再执行来源获取和转换命令；不向全局 Python 安装：

```powershell
.\.venv\Scripts\python.exe -m ensurepip --upgrade
.\.venv\Scripts\python.exe -m pip install pdfplumber pypdf python-docx
.\.venv\Scripts\python.exe tools\fetch_cet6_sources.py
.\.venv\Scripts\python.exe tools\fetch_cet6_alt_sources.py
.\.venv\Scripts\python.exe tools\import_cet6_reading.py
```

前两个命令下载到 `data/source-materials/`，按来源索引验证文件大小与 Git blob SHA。专用转换器生成 `data/imports/cet6-reading-2023-2025.json` 和 `cet6-reading-report.json`；转换成功的包可在网页“题库与数据”选择“导入题库”导入。命令报错时查看对应报告，不要将缺失选项、无法对应的答案或只有局部文章的材料当作完整阅读。

转换器默认读取随代码发布的两个核对索引：

- `web/cet6-reading-answer-index.json`：只含题号、答案字母、出处、来源指纹、页码与核对方法，不附原题文章、题干或解析。
- `web/cet6-reading-correction-index.json`：只含少量标签或字形校正、适用范围和来源指纹，用来处理提取时的错标；不提供完整原文替换。

因此新用户无需取得本次个人 `data/` 目录，也能按公开索引下载支持的来源、使用核对记录进行转换。遇到扫描答案 PDF 时，可使用已记录出处的字母索引；原卷末页有完整 `KEYS` 时优先读取该卷答案。源文件与指纹不一致、校正定位不唯一或核对记录有无法辨认项时会报错，不将缺失内容编造成题目。公开索引记录社区核对结果，仍不标为官方核验。

`--answers-checked`、`--corrections` 可显式指定自己保存在本地的核对文件；不指定时使用上面的公开默认文件。自行补充时应以对应公共索引的结构为参考，先检查原卷、题号、选项与答案出处，并把自己的文件保存在 `data/imports/`。不要只修改文件名套号就套用另一卷答案。

备用索引另含 [LoveItsukaKotori/cet6-training-app](https://github.com/LoveItsukaKotori/cet6-training-app) 固定版本的 2024 年 6 月、2025 年 6 月三套原卷，共六份 PDF。这些小文件已实际取得，具备文字层和末页 `KEYS`，可减少扫描卷 OCR 的缺字问题；引用答案仍需按文章、题号和选项核对，不能只依文件套号。可以单独获取这些文件：

```powershell
.\.venv\Scripts\python.exe tools\fetch_cet6_alt_sources.py --source loveitsuka
```

来源版本固定为 `b3fb51a75607ab29e595be955816699d8a5ba0e4`，下载器验证每份文件的大小和 Git blob SHA；当前缓存核验实测六份成功、零失败。完整题目通过来源下载后只保存在本地，公开索引不含原题正文。

转换检查选词填空 26—35、长篇匹配 36—45、仔细阅读 46—55 的文章、选项与答案；三部分合计应为 30 题。它记录成功与失败范围，不以下载文件数推算套数。原卷索引在 `web/source-index.json`，备用来源索引在 `web/cet6-alt-source-index.json`，公开文件只有元数据。六级补齐的最终套数与题目数以已导入结果为准，本节不预先声明 18 套全部完成。

## 四六级单词词书

已经实际取得并导入 ECDICT 词表，来源版本固定为 `bc015ed2e24a7abef49fc6dbbb7fe32c1dadaf8b`。它不是红宝书或其他出版社的商业词书。

| 词书 | 筛选规则 | 词条数 | 缺音标 |
| --- | --- | ---: | ---: |
| ECDICT 四级词表（CET4） | 来源标签包含 `cet4` | 3,849 | 12 |
| ECDICT 六级词表（CET6） | 来源标签包含 `cet4` 或 `cet6`，含四级基础 | 5,805 | 31 |

两本合计 **5,805 个不同单词**，全部有中文释义，没有来源例句时保持为空。同一个单词通过 `books` 记录所属词书，复习次数与安排共享；旧版本 `book` 单词书记录仍兼容。原演示词书已移除，与真实词表相同的词保留已产生的复习记录并归入真实词书。

在项目目录执行：

```powershell
.\.venv\Scripts\python.exe tools\import_wordbooks.py --download
```

这个命令的网络下载、指纹校验与转换已经实测成功。它下载约 66MB 的 CSV，限制源文件大小，并核对固定版本的 Git blob SHA；输出 `data/imports/cet4-words.json`、`cet6-words.json`，不自动修改学习数据库。网页导入操作见 [Windows 词书步骤](Windows上手指南.md#取得-ecdict-四级六级词表)。已有缓存时可以去掉 `--download`。

`wordbook-import-report.json` 记录源文件 SHA-256、词条数量、缺失字段和跳过原因，`ECDICT-LICENSE.txt` 保留上游 MIT 许可及 `Copyright (c) 2025 Linwei`。原词库、导出 JSON 与本地数据库都留在 `data/`，不提交到公开仓库。

## 旧版本演示材料清理

新安装不会生成演示材料。升级已有版本时，如希望移除旧演示练习和演示词书，可先导出网页备份，再执行：

```powershell
.\.venv\Scripts\python.exe tools\clean_learning_library.py
```

工具先在 `data/recovery/` 保存完整学习数据快照，再删除 `source_kind: demo` 的练习及其对应演示作答，移除演示词书归属，并去掉标题末尾的“待校对”。同时属于其他词书的词不会删除；真实练习、其作答和来源校对字段保留。`examples/` 中的原创文件只是格式参考，不会在启动时重新入库。
