# 路线图

## v0.1：先打通个人学习流程

这一阶段的发布范围为统一本地网页、四级/六级内容包导入、选择题判分、AI 答疑与写作翻译参考评分、词书导入、音频练习及本地记录备份。

验收重点：导入错误能明确提示；客观题按原始答案判分；AI 失败不记为有效评分；学习记录重启后可读取；个人内容与 API 密钥不进入代码仓库。新安装默认空库，原创样例仅作格式参考。

当前本地已导入六级 2023—2025 年 18 套完整阅读、540 题，四级 2024—2025 年 12 套完整阅读、360 题，以及 39 组写作与翻译、78 题。已提供 ECDICT 四级 3,849 词、六级 5,805 词的本地获取工具和词书选择功能。进度与可复现步骤见 [近三年题库整理](近三年题库整理.md)。

## 下一阶段：少量完整真题内容包

- 选取来源与使用范围清楚的四级、六级套卷。
- 对照原卷核验文章、题干、选项、答案与考次套卷关系。
- 单独记录解析和参考译文的来源。
- 补充真实音频、全文字幕与句子时间位置，检验逐句循环体验。
- 为 AI 批改准备有人工参考评分的样本，检查稳定性和偏差。

## 后续：近十年资料的系统整理

目标范围先明确为 2016—2025 十个完整年份；2026 年及后续考次作为增量。每个考次建立原卷、答案、听力、原文和使用权限的缺口表，在实际校对完成前不宣称“十年全量”。

题库整理应保留出处和版本记录，并区分真题原文、第三方解析与 AI 解释。增加 PDF 辅助识别或自动对齐前，需要明确其校对流程。

## 词汇与部署改进

- 整理可再分发的基础词库，扩大例句与练习形式。
- 取得相应授权后，增加红宝书等商业词书的官方内容包。
- 增加更细的复习计划、错题统计和跨设备迁移体验。
- 在验证 Windows 安装与升级流程后提供独立安装包。
- 多人账户、公网部署、离线模型与语音自动识别作为独立后续需求评估。

以上为方向，不代表已实现功能，也不构成具体发布日期承诺。
