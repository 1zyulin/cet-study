# Windows 上手指南

这份指南从下载项目开始，直到完成第一次练习和备份。项目在电脑本地运行，用 Edge 或 Chrome 打开网页；运行程序的窗口需要保持打开。

**当前内置内容是两套自创演示练习和 20 个演示单词。**十年完整真题、考试音频及红宝书等商业词书尚未附带；真实内容需要按格式另行导入。

## 1. 准备 Python

若电脑已经安装 Python，先在开始菜单打开 PowerShell，输入：

```powershell
py -3 --version
```

如果显示 `Python 3.10` 或更新版本，可以继续下一步。若提示找不到 `py`，再试 `python --version`。如果只是打开 Microsoft Store 或两个命令都不可用，需要安装 Python。

打开 [Python 官方 Windows 下载页](https://www.python.org/downloads/windows/)。选择完整 Python 安装方式；不要选择供程序嵌入使用的 **embeddable package**。传统安装器中如有 “Add python.exe to PATH” 选项，勾选它；按安装器说明完成后，关闭旧终端并重新打开。

如果选择新的 Python install manager，按 [官方 Windows 安装说明](https://docs.python.org/3/using/windows.html) 先安装一个 Python 运行时，例如：

```powershell
py install 3.12
py -3 --version
```

这是你准备电脑环境的步骤。项目启动脚本只使用已经安装的 Python，不替你安装 Python 运行时，也不向全局 Python 环境安装项目依赖。

## 2. 下载并解压项目

1. 在项目 GitHub 页面点击绿色 **Code** 按钮，选择 **Download ZIP**。
2. 在文件资源管理器里右键 ZIP，选择“全部提取”。不要直接在压缩包内部启动。
3. 打开解压后的文件夹，确认能看到 `start.ps1`、`run.py`、`requirements.txt` 和 `examples` 文件夹。
4. 将项目放在你有写入权限、可以长期保存的位置，例如个人文档里的 `CET-Study` 文件夹。

后续产生的学习记录保存在这个项目的 `data` 文件夹内。换位置可以整体复制项目；升级代码时应保留已有 `data`，不把它覆盖为其他人的内容。

## 3. 首次启动

推荐从终端启动，首次出现错误时提示会留在屏幕上：

1. 在刚才的项目文件夹空白处右键，选择“在终端中打开”。
2. 输入下面这一行并回车：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

3. 首次启动会创建 `.venv` 文件夹并从网上安装 Python 依赖。这些包只安装到项目环境；需要正常网络连接。
4. 看到本地地址后，等待浏览器打开。如果没有自动打开，在 Edge / Chrome 地址栏输入 [http://127.0.0.1:8765](http://127.0.0.1:8765)。

`ExecutionPolicy Bypass` 仅用于本次启动进程，不永久更改电脑的执行策略。如果单位电脑仍禁止脚本，使用下面的手动方式，不需要更改系统安全设置：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

若没有 `py` 但 `python --version` 正常，第一行换成 `python -m venv .venv`。手动方式同样只向项目环境安装依赖。

也可以在文件资源管理器里右键 `start.ps1`，选择“使用 PowerShell 运行”。Windows 双击 `.ps1` 可能只打开编辑器，**不是程序启动失败**。若右键启动窗口一闪而过，请改用终端方式查看具体提示。

再次使用时重复启动步骤即可；依赖齐全时不会再次安装。关闭学习网页不会自动停止服务。结束学习时回到启动窗口按 `Ctrl+C`，或关闭该窗口。

## 4. 完成第一次练习

左侧“真题练习”中会显示四级与六级的功能演示内容。这些练习清楚标记为自创样题。

1. 选择一套演示练习，完成阅读部分的两道选择题。
2. 提交作答，查看正确答案和解析。选择题判分不需要 AI。
3. 写作与翻译填写自己的英文答案；配置模型后才能进行 AI 批改。
4. 在“练习记录”查看提交记录；退出程序后再次打开，记录仍在本机。

“单词复习”内可以先使用演示词书，之后再导入自己的单词。听力需要先上传匹配题目的音频；项目未预装真实考试音频。

## 5. 设置 AI 答疑与批改

打开左侧 **“模型设置”**，填写三个字段：

| 字段 | 填写方法 |
| --- | --- |
| Base URL / API 地址 | 服务商提供的兼容接口根地址，例如 `https://api.deepseek.com/v1` |
| 模型名 | 服务商支持的准确名称，例如 `deepseek-chat` |
| API Key | 你自己的密钥，不是网站登录密码 |

点击 **“保存设置”**。保存只是保存配置，不能证明模型已经成功连接。回到练习页面提出一个简短问题，看到实际回复后，才能确认调用成功。写作和翻译可以获得 **15 分制参考评分**；它不等于官方考试评分或 710 分制成绩。

服务端会追加 `/chat/completions`，所以 API 地址通常填到 `/v1`，无需自行再追加完整请求路径。不同服务商可能使用不同根地址，按其文档填写；此示例不表示所有兼容服务都已实测。

外部 API 地址须为 HTTPS 且需要密钥。已经在电脑部署本机兼容模型时，可以填 `http://127.0.0.1:实际端口/v1` 或 `http://localhost:实际端口/v1`，密钥可留空；这里的端口与模型名必须换成实际值。本项目不会自动下载或安装本机大模型。

云端服务可能按调用计费。请求时，当前相关题目、学生作答和聊天内容会发送到你配置的接口。API Key 保存在本机设置中，不随 GitHub 代码和网页 JSON 备份发布。

## 6. 导入真题与听力

目前导入的是 **UTF-8 JSON 内容包**，不是直接上传 PDF。格式详见 [内容格式说明](content-format.md)。

1. 先查看 `examples/demo-exams.json`，了解一套题库包含的字段。
2. 以个人持有的真实资料整理文章、题干、选项、正确答案和来源。
3. 在“题库与数据”点击 **“导入题库”**，选择准备好的 JSON 文件。
4. 若文件缺少答案、含重复 ID 或不符合格式，网页会提示错误，按提示修改后再导入。

`examples/empty-real-exam-template.json` 是刻意留有缺失字段的空白模板；需要填完，不能直接作为真实题库导入。`source_kind: "past_paper"` 用于真题，`source.verified` 表示制作者的校对声明，不表示软件已经核定真实性和授权。

听力音频的操作顺序：

1. 在“题库与数据”点击 **“上传音频”**，选择自己的 MP3、WAV、M4A 或 OGG。
2. 复制上传后返回的 `/media/文件标识.mp3` 形式地址。
3. 把地址填写到对应听力部分的 `audio_url`，再导入内容包。
4. 音频和题目要对应同一套材料；逐句功能还需要经过校对的 `segments` 时间轴。

每个上传文件限 32MB。浏览器能否播放取决于实际音频编码。音频不包含在导出的 JSON 备份里。

## 7. 导入个人词书

打开“单词复习”，选择 **“导入词书”**。支持 CSV、TXT 和 JSON。

最容易的方法是使用 CSV：在 Excel 中建立四列，列名分别为 `word`、`meaning`、`phonetic`、`example`，然后另存为 **CSV UTF-8**。其中单词与释义需要填写，音标和例句可以为空。现有 Excel 工作簿应先转为 CSV。

可先复制 `examples/demo-words.csv` 再修改。TXT 支持每行 `单词,释义` 或使用制表符分隔；JSON 是包含这些字段的对象数组，例子见 [内容格式](content-format.md)。

个人导入商业词书不会使其内容自动变成开源资料；项目目前没有附带红宝书等商业词书。公开提交或分享内容包前，应核实相应使用权。

## 8. 备份、迁移与恢复

在“题库与数据”点击 **“导出备份”**，保存下载的 JSON 文件。它包含题库、作答记录和单词复习数据；不包含音频、模型设置和 API Key。

迁移到另一台电脑的完整步骤：

1. 在旧电脑导出 JSON 备份，并另外复制项目里的 `data/audio` 文件夹。
2. 在新电脑安装 Python、下载项目并启动一次。
3. 在新电脑网页选择 **“恢复备份”**，导入 JSON。该操作会替换当前学习记录。
4. 将旧电脑 `data/audio` 中的音频复制到新项目相同目录，保留文件名，不重新命名。
5. 在“模型设置”重新填写接口地址、模型名和密钥。

恢复前，程序会自动在 `data/recovery` 保存当前学习数据快照。如需撤销，从该目录找到对应 JSON 文件，再通过“恢复备份”导入。快照同样没有音频和密钥。分享程序源码时，不要把自己的 `data` 或备份上传到 GitHub。

## 9. 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 提示找不到可用 Python | 完成第 1 步安装并重新打开终端；商店占位命令不是已安装的运行环境 |
| 依赖下载失败 | 确认网络后重复启动；失败时不会改动已有学习记录 |
| 提示缺少 pip | 启动脚本会尝试在 `.venv` 内准备 pip；若失败，确认使用完整 Python 安装 |
| 地址无法打开 | 确认启动窗口仍在运行，并输入完整 `http://127.0.0.1:8765`；关闭窗口后网页无法继续访问 |
| 8765 端口已占用 | 在项目目录运行 `.\.venv\Scripts\python.exe run.py --port 8766`，使用提示的新地址 |
| 没有自动打开 Edge / Chrome | 系统默认浏览器会被打开；可以自行在 Edge / Chrome 输入本地地址 |
| AI 提示权限或密钥错误 | 检查密钥、模型名、HTTPS 接口地址及服务额度，保存设置后重试 |
| AI 提示超时或格式错误 | 稍后重试或更换兼容模型；失败结果不会作为有效评分 |
| 音频播放失败 | 检查 `data/audio` 文件是否存在、地址是否匹配，以及浏览器是否支持实际编码 |
| 重启后提示会话更新 | 刷新网页，使页面获得新的本地会话，再重试提交 |

不要为了排错直接删除 `data`。它包含你的题库、记录、音频和设置；清理或重装前应先备份。
