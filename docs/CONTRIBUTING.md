# 参与贡献

欢迎改进学习流程、导入校验、可访问性、模型兼容性与文档。提交前先确认改动范围与可验证的结果。

## 本地开发

按照根目录 README 安装 Python 依赖，然后运行：

```sh
python run.py
python -m unittest discover -s tests
```

运行测试时不要使用真实 API 密钥或消耗付费额度。模型相关测试应使用模拟响应，覆盖正常结果、超时或请求失败、无效 JSON 与超出范围的分数。

适合补充的测试包括：题目 ID 冲突、选择题答案不存在于选项、异常内容包、词书格式、历史记录持久化与备份恢复。避免只复制实现逻辑的测试。

## 提交要求

- 描述用户触发问题的方式，以及修改后的行为。
- 列出实际运行过的验证；没有实测的部分应说明。
- 界面改动尽量提供截图或操作步骤。
- 保留第三方版权和许可证说明，新增依赖说明其用途。
- 不提交个人 `data/`、`.env`、API 密钥、个人备份或受限音频。

## 内容贡献

真题、答案、解析、词书和音频分别记录来源与权利状态。不能仅因为文件出现在公开仓库就认为获得再分发授权。提交内容包时应附字段校验、校对范围与缺失项说明；未完成校对的内容保持 `verified: false`。

自创练习请使用 `source_kind: "demo"` 并明确标注演示。不要虚构官方来源、把 AI 生成题目标为真题，或把 AI 参考评分标为正式考试成绩。

## 代码组织

- `app/`：题库、记录、导入、AI 和本地服务。
- `web/`：网页界面与交互。
- `examples/`：可公开分发的示例，不放个人真题资料。
- `tests/`：有意义的功能与错误处理验证。
- `docs/`：格式、开发与路线说明。

程序按单人本地应用设计。涉及联网暴露、多人数据或数据格式变更的贡献，应说明兼容与迁移办法。
